# 输出解析器 Output Parsers

输出解析器（Output Parsers）是 Model I/O 中的 **Output** 部分——把模型返回的纯文本，转换成你的代码能直接消费的结构。

## 1. StringOutputParser

最常用：剥掉多余包装，直接拿到字符串。

```ts
import { StringOutputParser } from "@langchain/core/output_parsers";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { ChatOpenAI } from "@langchain/openai";

const chain = ChatPromptTemplate.fromTemplate("{q}")
  .pipe(new ChatOpenAI())
  .pipe(new StringOutputParser());

const text = await chain.invoke({ q: "用一句话解释 Token" });
```

<Callout type="info" title="为什么需要它">
模型 `invoke` 返回的是 `AIMessage` 对象，`.content` 才是文本。`StringOutputParser` 帮你省掉 `.content` 这一步，并兼容流式。
</Callout>

## 2. JsonOutputParser

当模型应返回 JSON（如提取字段、生成配置）时使用，自动 `JSON.parse` 并可选 schema 校验：

```ts
import { JsonOutputParser } from "@langchain/core/output_parsers";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { ChatOpenAI } from "@langchain/openai";

const parser = new JsonOutputParser();

const prompt = ChatPromptTemplate.fromTemplate(
  "提取以下句子的信息，返回 JSON：\n{text}\n{format_instructions}"
);

const chain = prompt.pipe(new ChatOpenAI()).pipe(parser);

const result = await chain.invoke({
  text: "张三，28 岁，来自上海。",
  format_instructions: parser.getFormatInstructions(),
});

console.log(result); // { name: "张三", age: 28, city: "上海" }
```

`parser.getFormatInstructions()` 会自动把「请输出如下 JSON 格式」的指令注入提示词，降低模型跑偏概率。

## 3. StructuredOutputParser

基于 Zod schema 定义结构，并生成人类可读的格式说明：

```ts
import { StructuredOutputParser } from "@langchain/core/output_parsers";
import { z } from "zod";

const parser = StructuredOutputParser.fromZodSchema(
  z.object({
    sentiment: z.enum(["正面", "负面", "中性"]),
    confidence: z.number().min(0).max(1),
  })
);

const chain = prompt.pipe(model).pipe(parser);
const out = await chain.invoke({ text: "这家店服务太差了" });
// { sentiment: "负面", confidence: 0.96 }
```

<Callout type="warn" title="别完全信任模型 JSON">
模型偶尔会输出非法 JSON 或字段不符。生产环境务必包裹 try/catch，并对关键字段做二次校验（如 Zod `.safeParse`）。
</Callout>

## 4. 解析器对比

| 解析器 | 适用场景 | 关键点 |
|---|---|---|
| `StringOutputParser` | 普通文本、流式 | 最轻量 |
| `JsonOutputParser` | 返回 JSON | 自动 parse + 格式指令 |
| `StructuredOutputParser` | 强结构 + 校验 | 依赖 Zod schema |

<Callout type="exercise" title="练习">
用 `StructuredOutputParser` + Zod，写一个「从用户评价里抽取 商品、评分、是否推荐」的链。

<Answer>
**参考答案：**

**完整实现**

```ts
import "dotenv/config";
import { z } from "zod";
import { StructuredOutputParser } from "@langchain/core/output_parsers";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { ChatOpenAI } from "@langchain/openai";

// 1) 用 Zod 定义目标结构，describe() 的文字会进入格式说明，等于给模型的字段级提示
const reviewSchema = z.object({
  product: z.string().describe("评价中提到的商品名称，找不到则填“未提及”"),
  rating: z.number().int().min(1).max(5).describe("综合评分，1-5 的整数"),
  recommended: z.boolean().describe("用户是否推荐该商品"),
});

const parser = StructuredOutputParser.fromZodSchema(reviewSchema);

// 2) 提示词里必须留一个位置注入 format_instructions
const prompt = ChatPromptTemplate.fromTemplate(
  `你是电商评价分析助手。请从下面这条用户评价中抽取结构化信息。

{format_instructions}

用户评价：
{review}`
);

const model = new ChatOpenAI({ model: "gpt-4o-mini", temperature: 0 });

// 3) 组链
const chain = prompt.pipe(model).pipe(parser);

// 4) 调用：把格式说明作为一个普通变量传进去
const result = await chain.invoke({
  review: "这款小米空气净化器 4 用了两周，噪音比想象中小，滤芯更换也方便，五星好评，推荐给有娃家庭。",
  format_instructions: parser.getFormatInstructions(),
});

console.log(result);
// { product: "小米空气净化器 4", rating: 5, recommended: true }
```

**用 `partial` 让调用更干净（推荐）**

每次 `invoke` 都手动传 `format_instructions` 很啰嗦，而且容易漏。用 `partial` 一次固定住：

```ts
const boundPrompt = await prompt.partial({
  format_instructions: parser.getFormatInstructions(),
});

const chain = boundPrompt.pipe(model).pipe(parser);

// 现在只需要传 review
const r = await chain.invoke({ review: "包装破损，客服还爱答不理，一分都不想给。" });
// { product: "未提及", rating: 1, recommended: false }
```

**生产加固：容错 + 二次校验**

课文提醒过「别完全信任模型 JSON」。`StructuredOutputParser` 解析失败会直接抛异常，批量处理时一条脏数据就能中断整个任务。实用做法是包一层安全调用：

```ts
type Review = z.infer<typeof reviewSchema>;

async function safeExtract(review: string): Promise<Review | null> {
  try {
    const raw = await chain.invoke({ review });
    // 双保险：即使解析器放过了，Zod 再校验一次范围与类型
    const checked = reviewSchema.safeParse(raw);
    if (!checked.success) {
      console.warn("字段校验未通过:", checked.error.issues);
      return null;
    }
    return checked.data;
  } catch (err) {
    console.warn("解析失败，原始评价:", review, (err as Error).message);
    return null;
  }
}

// 批量抽取，失败的自动过滤掉
const reviews = [
  "耳机音质不错，就是续航一般，给个四星。",
  "??????",                                  // 无意义输入，模型可能乱答
];
const parsed = (await Promise.all(reviews.map(safeExtract))).filter(Boolean);
```

**要点小结**

| 要点 | 说明 |
|---|---|
| `describe()` 不是注释 | 它会被写进 `getFormatInstructions()` 的输出，直接影响模型理解字段含义，务必写清楚 |
| `format_instructions` 必须注入 | 忘了留占位符，模型不知道要输出什么形状，解析几乎必失败 |
| `temperature: 0` | 抽取任务要确定性，不要让模型自由发挥 |
| `z.infer` 白拿类型 | `z.infer<typeof reviewSchema>` 直接得到 TS 类型，schema 改了类型自动跟着变，不用手写 interface |
| `.safeParse` 兜底 | 解析器只保证「是合法 JSON 且大致符合结构」，边界值（如 rating 超出 1-5）仍需 Zod 再校验一次 |

**进阶方向**：如果模型经常输出非法 JSON，可以套一层 `OutputFixingParser` 自动修复（第 19 章）；如果用的是支持 function calling 的模型，`model.withStructuredOutput(reviewSchema)` 由模型侧保证结构，成功率比纯提示词约束更高。
</Answer>

## 小结

- `StringOutputParser`：文本 → 字符串，最常用的收尾一环
- `JsonOutputParser`：自动解析 JSON，配合 `getFormatInstructions()`
- `StructuredOutputParser` + Zod：强类型结构化输出
- 解析结果务必做容错校验
