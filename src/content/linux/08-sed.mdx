# 文本三剑客之 sed：流编辑器与批量替换

sed（Stream EDitor，流编辑器）解决"改"的问题：批量替换配置里的域名、删掉文件的某些行、给每行加前缀——不打开编辑器，一条命令完成。它的工作模型很简单：**逐行读入 → 按脚本处理 → 打印结果**，原文件默认不动（除非 `-i`）。

## 1. s 命令：替换

sed 使用率 90% 以上的功能就是 `s`（substitute）：

```bash
sed 's/旧/新/' file        # 每行替换第一处匹配
sed 's/旧/新/g' file       # g 标志：每行替换全部匹配
sed 's/旧/新/2' file       # 只替换每行的第 2 处
sed 's/旧/新/gi' file      # i 标志：忽略大小写
```

模式部分是正则表达式（加 `-E` 用扩展正则，与 grep -E 同一套）。分隔符不是必须用 `/`——处理路径、URL 时换个分隔符可读性天差地别：

```bash
sed 's/\/var\/www\/old/\/var\/www\/new/' cfg     # 斜杠地狱，别这么写
sed 's#/var/www/old#/var/www/new#' cfg           # 用 # 做分隔符，清爽
sed 's|http://old.com|https://new.com|g' cfg     # 用 | 也行
```

## 2. 地址：只处理某些行

sed 命令前可以加"地址"限定作用范围，形式是行号或正则：

```bash
sed '3s/a/b/' file          # 只在第 3 行替换
sed '2,5s/a/b/g' file       # 第 2 到 5 行
sed '/^#/s/a/b/' file       # 只在注释行（# 开头）里替换
sed '/BEGIN/,/END/s/a/b/'   # 从匹配 BEGIN 的行到匹配 END 的行
sed '$s/a/b/' file          # $ 表示最后一行
```

## 3. d 删除与 p 打印

```bash
sed '/^#/d' app.conf        # 删除所有注释行
sed '/^$/d' app.conf        # 删除所有空行
sed '1d' file               # 删除第一行（如去掉 CSV 表头）
sed -n '5,8p' file          # -n 关闭默认输出，p 打印：只输出 5~8 行
sed -n '/ERROR/p' file      # 等价于 grep ERROR
```

`-n` 加 `p` 的组合要理解：sed 默认把每行处理完都打印一遍，`-n` 关掉这个默认行为，只有被 `p` 命令点名的行才输出——这就变成了"精确取行"工具，比 head+tail 组合更直接。

## 4. -i：原地编辑

前面所有例子都只改输出、不动原文件。加 `-i`（in-place）直接写回：

```bash
sed -i 's/8080/9090/' app.conf           # 直接修改文件
sed -i.bak 's/8080/9090/' app.conf       # 修改前先留一份 app.conf.bak（推荐）
sed -i '/^debug/d' /etc/app/*.conf       # 批量修改多个文件
```

<Callout type="warn" title="GNU sed 与 BSD/macOS sed 的 -i 不兼容">
Linux（GNU sed）：`sed -i 's/a/b/' f` 直接可用，`-i.bak` 表示留备份。macOS（BSD sed）：`-i` 后面**必须**跟备份后缀参数，不留备份要写 `sed -i '' 's/a/b/' f`（注意空字符串）。跨平台脚本要么统一装 gsed，要么用 `sed 's/a/b/' f > tmp && mv tmp f` 的通用写法。本课沙箱是 GNU sed。
</Callout>

## 5. 进阶一瞥：分组回引与 &

替换部分可以引用模式里捕获的内容：`&` 代表整个匹配，`\1` `\2` 代表 `-E` 模式下第 1、2 个括号分组：

```bash
# & ：给每个数字加上方括号
echo 'port 8080 and 9090' | sed -E 's/[0-9]+/[&]/g'
# 输出：port [8080] and [9090]

# \1 \2 ：调换 "key = value" 为 "value = key"
echo 'name = ada' | sed -E 's/(\w+) = (\w+)/\2 = \1/'
# 输出：ada = name

# 实战：从 nginx 日志行提取 IP（把整行替换成第一个字段）
echo '10.2.3.4 - - [31/Jul/2026] "GET /"' | sed -E 's/^([0-9.]+) .*/\1/'
# 输出：10.2.3.4
```

sed 还有追加（a）、插入（i）、行内换行处理等更多命令，但工作中"替换 + 删除 + 取行"三板斧覆盖了绝大多数需求；更复杂的字段级逻辑，下一章的 awk 更合适。

## 6. sed 与 grep 的配合分工

| 需求 | 工具 |
|---|---|
| 找出包含 X 的行 | grep |
| 把 X 换成 Y | sed s |
| 删掉某些行 / 取某区间 | sed d / sed -n p |
| 按列取值、算数、统计 | awk（下一章） |

管道里三者常串着用：`grep 先缩小范围 → sed 清洗格式 → awk 统计`，第 20 章会看到完整流水线。

## 小结

- 模型：逐行读入、处理、输出；默认**不修改原文件**
- `s/旧/新/g` 是绝对主力；分隔符可换成 `#` `|` 避免斜杠地狱；`-E` 用扩展正则
- 地址限定范围：行号、`2,5`、`/正则/`、`$`（末行）
- `/^#/d` 删注释、`/^$/d` 删空行、`-n '5,8p'` 精确取行
- `-i` 原地改，建议 `-i.bak` 留备份；注意 macOS 的 BSD sed 语法差异
- `&` 与 `\1` 分组回引，能做"提取重排"类改写
- 下一章：三剑客之 awk——按列处理与统计报表 →

**参考答案：**

**第 1 题：一条 sed 删注释、删空行并替换 localhost**

```bash
cat > app.conf << 'EOF'
# main config
db_host = localhost
port = 8080

# cache
cache_host = localhost
EOF

sed -e '/^#/d' -e '/^$/d' -e 's/localhost/127.0.0.1/' app.conf
```

三种写法等价（分号串联 / 多个 `-e`）：

```bash
sed '/^#/d; /^$/d; s/localhost/127.0.0.1/' app.conf
sed -e '/^#/d' -e '/^$/d' -e 's/localhost/127.0.0.1/' app.conf
```

`/^#/d` 删注释行，`/^$/d` 删空行，`s/localhost/127.0.0.1/` 做替换，三个命令依次作用于每一行。

**第 2 题：两种方式取第 3~6 行，结果一致**

```bash
seq 10
sed -n '3,6p'        # 输出 3 4 5 6
seq 10 | sed -n '3,6p'

seq 10 | head -n 6 | tail -n 4   # 也是 3 4 5 6
```

两者结果一致。区别：`sed -n '3,6p'` 一步到位且语义直接；`head | tail` 需要心算区间（取第 A~B 行 = `head -n B | tail -n (B-A+1)`），sed 更省心。

**第 3 题：`sed -i.bak` 批量替换 http 为 https**

```bash
printf 'site = http://example.com/api\ncdn = http://static.example.com\n' > app.conf

sed -i.bak 's|http://|https://|g' app.conf
# 用 | 做分隔符，避免转义 http:// 里的斜杠

cat app.conf       # 两处都已变成 https://
diff app.conf app.conf.bak
# diff 显示 - http:// 行与 + https:// 行，其余无变化
```

`-i.bak` 会在修改前自动备份一份 `app.conf.bak`，`diff` 可对比确认只改了目标内容。

**第 4 题：分组回引调换字段顺序**

```bash
echo 'user=ada id=42' | sed -E 's/(user=)([a-z]+) (id=)([0-9]+)/\3\4 \1\2/'
# 输出：id=42 user=ada
```

思路：用两组括号分别捕获 `user=ada` 与 `id=42`，然后调换顺序输出。更简洁的写法是只捕获取值部分：

```bash
echo 'user=ada id=42' | sed -E 's/user=([a-z]+) id=([0-9]+)/id=\2 user=\1/'
# 输出：id=42 user=ada
```

`\1` 引用第一个括号组 `ada`，`\2` 引用第二个括号组 `42`，替换文本把它们按目标顺序拼起来。
