# 文档加载

RAG 的第一步是把原始文件变成**纯文本 + 元数据**。这一步看似简单，却直接决定了后续能检索到什么。不同格式有不同坑：PDF 的表格、Word 的批注、网页的导航噪声都需要在加载阶段处理。

## 1. 什么是 Loader

Loader 的核心职责：

- 提取正文文本，尽量丢掉页眉/页脚/广告等噪声
- 保留结构化信息（标题层级、表格）
- 产出**元数据**（来源、页码、作者、修改时间），供后续过滤与引用

统一的数据结构通常是一个 `Document`：`{ page_content: str, metadata: dict }`。

## 2. 常见格式与对应方案

| 格式 | 推荐方案 | 注意点 |
|---|---|---|
| PDF | `PyPDF`、`pdfplumber`、`unstructured` | 扫描件需 OCR；表格易乱 |
| Word(.docx) | `python-docx`、LangChain `Docx2txtLoader` | 批注/修订可能混入 |
| 网页/HTML | `BeautifulSoup`、`trafilatura`、`readability` | 先去 nav/footer/JS |
| Markdown | 直接读，按标题切 | 天然带层级 |
| 纯文本 | 直接读 | 编码问题（utf-8） |
| CSV/JSON | 逐行/逐字段转文本 | 决定哪些列参与检索 |

<Callout type="info" title="元数据是金矿">
`metadata` 里尽量带上 `source`、`page`、`title`。后面做「按部门过滤」「引用到具体页码」都靠它。
</Callout>

## 3. 代码示例：多格式加载

```python
from langchain_community.document_loaders import (
    PyPDFLoader, UnstructuredWordDocumentLoader,
    WebBaseLoader, TextLoader
)

# PDF：每个 page 是一个 Document
pdf = PyPDFLoader("手册.pdf")
pdf_docs = pdf.load()
print(pdf_docs[0].metadata)   # {'source': '手册.pdf', 'page': 0}

# Word
docx = UnstructuredWordDocumentLoader("合同.docx")
docx_docs = docx.load()

# 网页（自动去噪）
web = WebBaseLoader("https://docs.example.com/intro")
web_docs = web.load()

# Markdown / 文本
txt = TextLoader("README.md", encoding="utf-8")
txt_docs = txt.load()
```

## 4. 网页加载的去噪技巧

很多网站正文外裹着大量导航和脚本，直接喂进去会污染检索。

```python
from bs4 import BeautifulSoup
import requests

html = requests.get("https://blog.example.com/post").text
soup = BeautifulSoup(html, "html.parser")
for tag in soup(["nav", "footer", "script", "style"]):
    tag.decompose()
text = soup.get_text(separator="\n", strip=True)
```

<Callout type="warn" title="PDF 表格与扫描件">
`PyPDFLoader` 对纯文字 PDF 友好，但遇到**扫描件图片**会读不到字，需要 OCR（如 `pdfplumber` + `tesseract`）；遇到**复杂表格**，文本顺序可能错乱，建议用 `unstructured` 或专门的表格抽取工具，详见第 15 章多模态 RAG。
</Callout>

## 5. 批量加载一个目录

```python
from langchain_community.document_loaders import DirectoryLoader

loader = DirectoryLoader(
    "./docs",
    glob="**/*.{pdf,docx,md,txt}",
    show_progress=True,
)
all_docs = loader.load()
```

<Callout type="tip" title="加载阶段就要想清楚切分">
加载出的 `Document` 往往很长。下一步「切分」可以把一个大 `Document` 切成多个小 `chunk`，并且每个 `chunk` 都继承原 `Document` 的 `metadata`，这样引用时能直接回溯到源文件与页码。
</Callout>

**参考答案：**

**第一步：加载并观察**

```python
from langchain_community.document_loaders import PyPDFLoader

docs = PyPDFLoader("员工手册.pdf").load()
first = docs[0]
print(repr(first.page_content[:800]))   # 用 repr 才能看清换行与空白
print(first.metadata)                   # {'source': '员工手册.pdf', 'page': 0}
```

用 `repr()` 而不是直接 print，因为噪声往往藏在换行和不可见字符里。

**第二步：典型噪声清单**

跑完通常会看到这几类垃圾：

- **页眉页脚**：每页重复的「XX公司内部资料」「第 3 页 / 共 42 页」
- **断行连字**：PDF 换行把一个词拆成 `retriev-\nal`，中文则是句子中间莫名断行
- **目录页**：大量「第一章……………12」这种点线
- **水印/版权声明**：每页固定出现
- **多栏错序**：双栏排版被按视觉行读成左右交替的乱序

**第三步：清洗策略**

最有效的思路是**「跨页重复即噪声」**——统计每一行在所有页出现的次数，出现率超过阈值的基本就是页眉页脚：

```python
from collections import Counter
import re

def build_noise_set(docs, ratio=0.6):
    """出现在 60% 以上页面的行，判定为页眉/页脚噪声"""
    counter = Counter()
    for d in docs:
        for line in set(d.page_content.splitlines()):
            counter[line.strip()] += 1
    threshold = len(docs) * ratio
    return {line for line, n in counter.items() if n >= threshold and line}

def clean(text, noise_set):
    lines = []
    for line in text.splitlines():
        s = line.strip()
        if not s or s in noise_set:
            continue
        if re.fullmatch(r"[-—\s]*第?\s*\d+\s*页?[-—\s]*", s):   # 纯页码行
            continue
        lines.append(s)
    text = "\n".join(lines)
    text = re.sub(r"(?<=[a-zA-Z])-\n(?=[a-zA-Z])", "", text)     # 英文断行连字
    text = re.sub(r"(?<=[\u4e00-\u9fa5])\n(?=[\u4e00-\u9fa5])", "", text)  # 中文误断行
    text = re.sub(r"\n{3,}", "\n\n", text)                        # 压缩空行
    return text

noise = build_noise_set(docs)
for d in docs:
    d.page_content = clean(d.page_content, noise)
```

**关键原则：**

1. **清洗一定要在切分之前做**。噪声若参与切分，会挤占 chunk 的有效字数，还会污染向量——每个 chunk 都带着「XX公司内部资料」，会让所有片段在向量空间里被拉近，降低区分度。
2. **清洗不要动 `metadata`**。`source` 和 `page` 是后面做引用溯源的命根子，只清洗 `page_content`。
3. **清洗后抽查几页再入库**。正则写猛了可能把正文也删掉，尤其是「纯数字行」规则容易误伤表格数据。
4. **多栏 PDF 单靠 PyPDF 救不了**，需要换 `unstructured` 或 `pdfplumber` 做版面分析，见第 15 章。
</Answer>

## 小结

- Loader 产出 `page_content` + `metadata`，尽量保留来源/页码
- PDF/Word/网页各有适合的库，网页要先去噪
- 扫描件需 OCR，复杂表格需专门抽取
- 加载后得到的长 Document 是下一步「切分」的输入
