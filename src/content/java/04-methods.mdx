# 方法

方法（method）是 Java 中组织代码的基本单位。

## 1. 基本定义

```java
[修饰符] 返回值类型 方法名(参数列表) {
    方法体
    return 返回值;
}
```

<Playground
  language="java"
  id="java-04-func"
  title="基本方法"
  code={`public class Main {
    // 静态方法
    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(3, 5));
        System.out.println(add(10, 20));
    }
}`}
  expectedOutput={`8\n30`}
/>

## 2. 参数传递

Java 中**基本类型**按值传递，**引用类型**按引用传递（传递的是引用的副本）。

<Playground
  language="java"
  id="java-04-pass"
  title="值传递 vs 引用传递"
  code={`public class Main {
    static void bump(int n) { n++; }                          // 改不动外面
    static void append(java.util.List<String> list) {
        list.add("added");                                    // 能改 list 内容
    }

    public static void main(String[] args) {
        int x = 10;
        bump(x);
        System.out.println("x = " + x);   // 10

        var list = new java.util.ArrayList<String>(java.util.List.of("a", "b"));
        append(list);
        System.out.println("list = " + list);  // [a, b, added]
    }
}`}
  expectedOutput={`x = 10\nlist = [a, b, added]`}
/>

<Callout type="info" title="Java 没有引用传递的引用">
Java 始终是**值传递**：对于引用类型，传的是引用的副本。但因为副本和原引用指向同一对象，所以能修改对象内容。重新赋值 `list = newList` 不会影响外面。
</Callout>

## 3. 方法重载

同名方法、不同参数（数量或类型），构成重载。

<Playground
  language="java"
  id="java-04-overload"
  title="方法重载"
  code={`public class Main {
    static int add(int a, int b)            { return a + b; }
    static double add(double a, double b)   { return a + b; }
    static String add(String a, String b)   { return a + b; }

    public static void main(String[] args) {
        System.out.println(add(1, 2));
        System.out.println(add(1.5, 2.5));
        System.out.println(add("Hello, ", "Java"));
    }
}`}
  expectedOutput={`3\n4.0\nHello, Java`}
/>

## 4. 可变参数 `varargs`

<Playground
  language="java"
  id="java-04-varargs"
  title="可变参数"
  code={`public class Main {
    static int sum(int... nums) {
        int s = 0;
        for (int n : nums) s += n;
        return s;
    }

    public static void main(String[] args) {
        System.out.println(sum());              // 0
        System.out.println(sum(1, 2, 3));       // 6
        System.out.println(sum(new int[]{1, 2, 3, 4, 5}));  // 15
    }
}`}
  expectedOutput={`0\n6\n15`}
/>

<Callout type="tip" title="varargs 的本质">
`int... nums` 等价于 `int[] nums`。调用时编译器会构造一个数组。**只能有一个 varargs 参数，且必须是最后一个**。
</Callout>

## 5. 静态工具方法集合

<Playground
  language="java"
  id="java-04-utils"
  title="工具方法"
  code={`public class Main {
    static int max(int a, int b) { return a > b ? a : b; }
    static int max(int a, int b, int c) { return max(max(a, b), c); }
    static double avg(int... nums) {
        if (nums.length == 0) return 0;
        long s = 0;
        for (int n : nums) s += n;
        return (double) s / nums.length;
    }

    public static void main(String[] args) {
        System.out.println(max(3, 7));
        System.out.println(max(3, 7, 2));
        System.out.println(avg(1, 2, 3, 4, 5));
    }
}`}
  expectedOutput={`7\n7\n3.0`}
/>

## 6. 递归

<Playground
  language="java"
  id="java-04-recursion"
  title="递归阶乘"
  code={`public class Main {
    static long fact(int n) {
        if (n <= 1) return 1;
        return n * fact(n - 1);
    }

    public static void main(String[] args) {
        for (int i = 0; i <= 6; i++) {
            System.out.println(i + "! = " + fact(i));
        }
    }
}`}
  expectedOutput={`0! = 1\n1! = 1\n2! = 2\n3! = 6\n4! = 24\n5! = 120\n6! = 720`}
/>

## 小结

- ✅ `static 返回值类型 方法名(参数)` 定义方法
- ✅ 基本类型按值传递；引用类型传引用的副本
- ✅ 方法重载：同名不同参
- ✅ `T... args` 可变参数（最多一个，必须在末尾）
- ✅ 递归必须有终止条件
