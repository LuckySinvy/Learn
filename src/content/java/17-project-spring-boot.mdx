# 项目：Spring Boot REST API

Spring Boot 是 Java 后端的事实标准。但它**需要 Maven/Gradle 与多文件**——Playground 跑不了。

本章的做法：
1. 先按 **真实项目结构** 拆文件展示（pom.xml、Application、Controller、Service、Model）
2. 再用 **JDK 自带**的 `com.sun.net.httpserver.HttpServer` 写一个**单文件可运行**的极简 HTTP 服务，体验「注解 + 路由 + 依赖注入」的核心思想

> 本章 Playground 不会发起真实网络请求（沙箱禁外网），全部用 `HttpClient` **访问本机**端口完成端到端演示。

### Controller

```java
package com.example.userservice.controller;

import com.example.userservice.model.User;
import com.example.userservice.service.UserService;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/users")
public class UserController {
    private final UserService service;

    public UserController(UserService service) {   // 构造器注入
        this.service = service;
    }

    @GetMapping
    public List<User> list() {
        return service.findAll();
    }

    @GetMapping("/{id}")
    public User get(@PathVariable Long id) {
        return service.findById(id);
    }

    @PostMapping
    public User create(@RequestBody CreateUserRequest req) {
        return service.create(req.name(), req.email());
    }
}
```

### Service

```java
package com.example.userservice.service;

import com.example.userservice.model.User;
import org.springframework.stereotype.Service;

import java.util.*;
import java.util.concurrent.atomic.AtomicLong;

@Service
public class UserService {
    private final Map<Long, User> store = new HashMap<>();
    private final AtomicLong seq = new AtomicLong(0);

    public List<User> findAll() {
        return store.values().stream().toList();
    }

    public User findById(long id) {
        User u = store.get(id);
        if (u == null) throw new NoSuchElementException("user " + id);
        return u;
    }

    public User create(String name, String email) {
        long id = seq.incrementAndGet();
        User u = new User(id, name, email);
        store.put(id, u);
        return u;
    }
}
```

<Callout type="info" title="Spring Boot 关键注解">
| 注解 | 作用 |
|---|---|
| `@SpringBootApplication` | 一键启用：自动配置 + 组件扫描 + 配置类 |
| `@RestController` | `@Controller` + `@ResponseBody`：方法返回值直接写响应体（JSON） |
| `@RequestMapping("/users")` | 类级别 URL 前缀 |
| `@GetMapping / @PostMapping` | 等价于 `@RequestMapping(method = GET/POST)` |
| `@PathVariable` | 取 URL 里的占位符 `/users/{id}` |
| `@RequestBody` | 把请求体 JSON 反序列化为对象 |
| `@Service / @Repository / @Component` | 把类注册成 Spring Bean |
</Callout>

## 2. 单文件 Playground：迷你 Spring

为了在 Playground 里也能跑起来，我们用 JDK 自带的 `HttpServer` 写一个**只有 80 行的「迷你 Spring」**——保留 `@RestController` / `@GetMapping` / `@PostMapping` / `@RequestBody` / 依赖注入的概念：

  code={`import com.sun.net.httpserver.*;
import java.io.*;
import java.lang.annotation.*;
import java.lang.reflect.*;
import java.net.*;
import java.nio.charset.StandardCharsets;
import java.util.*;
import java.util.concurrent.*;

public class Main {
    // ====== 注解（同名于 Spring） ======
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.TYPE)
    public @interface RestController {}
    @Retention(RetentionPolicy.RUNTIME) @Target({ElementType.TYPE, ElementType.METHOD})
    public @interface RequestMapping { String value() default ""; }
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.METHOD)
    public @interface GetMapping { String value() default ""; }
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.METHOD)
    public @interface PostMapping { String value() default ""; }
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.PARAMETER)
    public @interface RequestBody {}
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.PARAMETER)
    public @interface PathVariable {}
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.METHOD)
    public @interface ResponseBody {}
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.TYPE)
    public @interface Component {}
    @Retention(RetentionPolicy.RUNTIME) @Target(ElementType.FIELD)
    public @interface Autowired {}

    // ====== 注解式 Controller（像 Spring 一样写） ======
    @RestController
    @RequestMapping("/users")
    static class UserController {
        @Autowired UserService service;   // 字段注入

        @GetMapping
        @ResponseBody
        public List<String> list() { return service.findAll(); }

        @GetMapping("/{id}")
        @ResponseBody
        public String get(@PathVariable("id") String id) {
            return service.findById(id);
        }

        @PostMapping
        @ResponseBody
        public String create(@RequestBody String name) {
            return service.create(name);
        }
    }

    @Component
    static class UserService {
        private final Map<String, String> store = new ConcurrentHashMap<>();
        public List<String> findAll() { return new ArrayList<>(store.values()); }
        public String findById(String id) {
            String u = store.get(id);
            if (u == null) throw new NoSuchElementException("user " + id);
            return u;
        }
        public String create(String name) {
            String id = String.valueOf(store.size() + 1);
            store.put(id, name);
            return "user#" + id + "=" + name;
        }
    }

    // ====== IoC 容器（依赖注入） ======
    static class AppContext {
        final Map<Class<?>, Object> beans = new HashMap<>();
        AppContext(Class<?>... components) throws Exception {
            // 1. 实例化所有 @Component / @RestController
            for (Class<?> c : components) {
                beans.put(c, c.getDeclaredConstructor().newInstance());
            }
            // 2. 注入 @Autowired 字段
            for (Object bean : beans.values()) {
                for (Field f : bean.getClass().getDeclaredFields()) {
                    if (f.isAnnotationPresent(Autowired.class)) {
                        f.setAccessible(true);
                        f.set(bean, beans.get(f.getType()));
                    }
                }
            }
        }
    }

    // ====== 路由注册（注解扫描） ======
    static class Router {
        record Handler(Object bean, Method m, String path, String httpMethod) {}

        void register(HttpServer server, AppContext ctx) {
            for (Object bean : ctx.beans.values()) {
                Class<?> c = bean.getClass();
                String classPath = "";
                if (c.isAnnotationPresent(RequestMapping.class)) {
                    classPath = c.getAnnotation(RequestMapping.class).value();
                }
                for (Method m : c.getDeclaredMethods()) {
                    String method = null, path = null;
                    if (m.isAnnotationPresent(GetMapping.class)) {
                        method = "GET";
                        path = m.getAnnotation(GetMapping.class).value();
                    } else if (m.isAnnotationPresent(PostMapping.class)) {
                        method = "POST";
                        path = m.getAnnotation(PostMapping.class).value();
                    }
                    if (method == null) continue;
                    final String fullPath = classPath + path;
                    Handler h = new Handler(bean, m, fullPath, method);
                    server.createContext(fullPath, exchange -> handle(exchange, h));
                }
            }
        }

        void handle(HttpServer.Exchange exchange, Handler h) throws IOException {
            try {
                String body = new String(exchange.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
                String path = exchange.getRequestURI().getPath();
                String[] segments = path.replace(h.path, "").split("/", -1);
                Object[] args = new Object[m(h).getParameterCount()];
                Parameter[] ps = m(h).getParameters();
                for (int i = 0; i < ps.length; i++) {
                    if (ps[i].isAnnotationPresent(RequestBody.class)) args[i] = body;
                    else if (ps[i].isAnnotationPresent(PathVariable.class)) {
                        String name = ps[i].getAnnotation(PathVariable.class).value();
                        args[i] = matchPathVar(h.path, path, name);
                    } else args[i] = null;
                }
                Object result = m(h).invoke(h.bean, args);
                byte[] out = (result == null ? "" : result.toString()).getBytes(StandardCharsets.UTF_8);
                exchange.sendResponseHeaders(200, out.length);
                exchange.getResponseBody().write(out);
            } catch (InvocationTargetException e) {
                String msg = e.getCause().getMessage();
                byte[] out = ("ERR: " + msg).getBytes(StandardCharsets.UTF_8);
                exchange.sendResponseHeaders(500, out.length);
                exchange.getResponseBody().write(out);
            } catch (Exception e) {
                String msg = e.getMessage();
                byte[] out = ("ERR: " + msg).getBytes(StandardCharsets.UTF_8);
                exchange.sendResponseHeaders(500, out.length);
                exchange.getResponseBody().write(out);
            } finally {
                exchange.close();
            }
        }

        Method m(Handler h) { return h.m; }
        String matchPathVar(String pattern, String actual, String name) {
            // 简单实现：/users/{id} -> 取 actual 里除了 pattern 以外的第一段
            String tail = actual.substring(pattern.length() + 1);
            return tail.split("/")[0];
        }
    }

    public static void main(String[] args) throws Exception {
        // 1. 启动容器
        AppContext ctx = new AppContext(UserController.class, UserService.class);
        HttpServer server = HttpServer.create(new InetSocketAddress("127.0.0.1", 0), 0);
        new Router().register(server, ctx);
        server.start();
        int port = server.getAddress().getPort();
        System.out.println("server up on http://127.0.0.1:" + port);

        // 2. 用 Java 自带 HttpClient 模拟 curl
        HttpClient client = HttpClient.newHttpClient();
        // POST /users
        HttpResponse<String> r1 = client.send(
            HttpRequest.newBuilder(URI.create("http://127.0.0.1:" + port + "/users"))
                       .header("Content-Type", "text/plain")
                       .POST(HttpRequest.BodyPublishers.ofString("Alice"))
                       .build(),
            HttpResponse.BodyHandlers.ofString());
        System.out.println("POST /users        -> " + r1.statusCode() + " " + r1.body());

        HttpResponse<String> r2 = client.send(
            HttpRequest.newBuilder(URI.create("http://127.0.0.1:" + port + "/users"))
                       .header("Content-Type", "text/plain")
                       .POST(HttpRequest.BodyPublishers.ofString("Bob"))
                       .build(),
            HttpResponse.BodyHandlers.ofString());
        System.out.println("POST /users        -> " + r2.statusCode() + " " + r2.body());

| Spring | 这里 |
|---|---|

| 路由映射 `@GetMapping` 等 | `Router.register` 扫注解 |
| JSON 序列化 | `toString()`（真实用 Jackson/Gson） |
| Tomcat 内嵌 | `com.sun.net.httpserver.HttpServer` |

## 3. 真实项目里的常见依赖注入方式

Spring 推荐**构造器注入**——更利于测试：

```java
@Service
public class OrderService {
    private final UserService userService;
    private final PaymentService paymentService;

    public OrderService(UserService u, PaymentService p) {   // 构造器注入
        this.userService = u;
        this.paymentService = p;
    }
}
```

字段注入（上一节的 `@Autowired` 字段）虽然写法短，但**不利于单元测试**——无法在没有 Spring 容器时手动传 mock。

## 小结

- ✅ Spring Boot 启动类标 `@SpringBootApplication`，`main` 一行启动
- ✅ `@RestController` + `@GetMapping` / `@PostMapping` 把方法变成 HTTP 端点
- ✅ `@RequestBody` 反序列化请求体；`@PathVariable` 取 URL 占位符
- ✅ 推荐**构造器注入**依赖，而非字段注入
- ✅ 没有 Spring 时也能用 `com.sun.net.httpserver` 写极简 HTTP 服务
- ✅ 本章 Playground 演示了「注解扫描 + 依赖注入 + 路由」三件套是怎么工作的
