# 第一个 Java 程序

Java 是一门**编译型 + 虚拟机**语言：源代码被 `javac` 编译为字节码，由 JVM 执行。

## 1. Hello, World!

## 2. 关键名词

- **JDK**：Java Development Kit（编译、调试、运行工具集）
- **JRE**：Java Runtime Environment（运行字节码）
- **JVM**：Java Virtual Machine（执行字节码的虚拟机）
- **字节码**：`.class` 文件，JVM 的指令集

```bash
javac Main.java     # 编译 -> Main.class
java Main           # 运行
```

## 3. `main` 方法签名

```java
public static void main(String[] args)
```

- `public`：JVM 调用，必须 public
- `static`：无需创建实例
- `void`：无返回值
- `args`：命令行参数

<Playground
  language="java"
  id="java-01-args"
  title="main 接收参数"
  code={`public class Main {
    public static void main(String[] args) {
        System.out.println("参数个数：" + args.length);
        for (int i = 0; i < args.length; i++) {
            System.out.println("  [" + i + "] " + args[i]);
        }
    }
}`}
/>

## 4. 输出方法

| 方法 | 用途 |
|---|---|
| `System.out.print(s)` | 不换行 |
| `System.out.println(s)` | 换行 |
| `System.out.printf(fmt, args)` | 格式化 |

<Playground
  language="java"
  id="java-01-printf"
  title="printf 格式化"
  code={`public class Main {
    public static void main(String[] args) {
        String name = "Alice";
        int age = 30;
        System.out.printf("姓名：%s，年龄：%d%n", name, age);
        System.out.printf("π = %.4f%n", Math.PI);
        System.out.printf("布尔：%b%n", true);
    }
}`}
  expectedOutput={`姓名：Alice，年龄：30\nπ = 3.1416\n布尔：true`}
/>

<Callout type="tip" title="%n vs \n">
Java 跨平台换行用 `%n`（Formatter）或 `System.lineSeparator()`，比 `\n` 更安全（Windows 下也是正确的换行符）。
</Callout>
