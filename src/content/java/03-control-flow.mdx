## 3. `switch`（Java 14+ 箭头语法）

<Playground
  language="java"
  id="java-03-switch"
  title="switch 箭头语法"
  code={`public class Main {
    public static void main(String[] args) {
        int day = 3;
        String name = switch (day) {
            case 1, 2, 3, 4, 5 -> "工作日";
            case 6, 7          -> "周末";
            default            -> "无效";
        };
        System.out.println(day + " -> " + name);
    }
}`}
  expectedOutput={`3 -> 工作日`}
/>

<Callout type="tip" title="箭头语法不再需要 break">
Java 14 引入 `case x -> ...`，每个 case 只执行匹配的分支，**不需要 break**。传统 `case x: ... break;` 仍可用。
</Callout>

## 4. `for` 循环

<Playground
  language="java"
  id="java-03-for"
  title="for 循环"
  code={`public class Main {
    public static void main(String[] args) {
        // 标准 for
        for (int i = 0; i < 5; i++) {
            System.out.print(i + " ");
        }
        System.out.println();

        // 增强 for（for-each）
        int[] nums = {10, 20, 30};
        for (int n : nums) {
            System.out.print(n + " ");
        }
        System.out.println();
    }
}`}
  expectedOutput={`0 1 2 3 4 \n10 20 30 `}
/>

## 5. `while` 与 `do-while`

<Playground
  language="java"
  id="java-03-while"
  title="while vs do-while"
  code={`public class Main {
    public static void main(String[] args) {
        // while：先判断再执行
        int i = 0;
        while (i < 3) {
            System.out.print(i++ + " ");
        }
        System.out.println();

        // do-while：先执行一次再判断
        int j = 10;
        do {
            System.out.println("至少执行一次: j = " + j);
        } while (j < 3);
    }
}`}
  expectedOutput={`0 1 2 \n至少执行一次: j = 10`}
/>

## 6. `break` 与 `continue`

<Playground
  language="java"
  id="java-03-break"
  title="break / continue / 带标签 break"
  code={`public class Main {
    public static void main(String[] args) {
        // 找第一个 7 的倍数
        for (int n = 1; n < 100; n++) {
            if (n % 7 == 0) {
                System.out.println("找到: " + n);
                break;
            }
        }

        // 跳过偶数
        for (int n = 1; n <= 10; n++) {
            if (n % 2 == 0) continue;
            System.out.print(n + " ");
        }
        System.out.println();

        // 带标签的 break（跳出多层循环）
        outer:
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                if (i == 1 && j == 1) break outer;
                System.out.printf("(%d,%d) ", i, j);
            }
        }
        System.out.println();
    }
}`}
  expectedOutput={`找到: 7\n1 3 5 7 9 \n(0,0) (0,1) (0,2) (1,0)`}
/>
