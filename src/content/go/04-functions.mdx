# 函数

## 1. 基本定义

```go
func add(a, b int) int {
    return a + b
}
```

## 2. 多返回值

Go 函数可以返回任意数量的值，这是它处理错误的惯用方式。

<Playground
  language="go"
  id="go-04-multi"
  title="多返回值"
  code={`package main

import "fmt"

func div(a, b int) (int, int) {  // 商, 余数
    return a / b, a % b
}

func main() {
    q, r := div(17, 5)
    fmt.Printf("17 ÷ 5 = %d 余 %d\\n", q, r)

    // 只用其中一个，另一个用 _ 忽略
    onlyQ, _ := div(10, 3)
    fmt.Println("商：", onlyQ)
}`}
  expectedOutput={`17 ÷ 5 = 3 余 2\n商： 3`}
/>

## 3. 命名返回值

返回值可以命名，函数体内直接赋值，末尾的 `return` 会自动返回它们。

<Playground
  language="go"
  id="go-04-named"
  title="命名返回值"
  code={`package main

import "fmt"

func rect(w, h int) (area, perimeter int) {
    area = w * h
    perimeter = 2 * (w + h)
    return  // 裸 return，返回命名值
}

func main() {
    a, p := rect(3, 5)
    fmt.Println("面积:", a, "周长:", p)
}`}
  expectedOutput={`面积: 15 周长: 16`}
/>

## 4. `defer` 延迟调用

`defer` 把语句推迟到**当前函数返回前**执行，常用于释放资源。

<Playground
  language="go"
  id="go-04-defer"
  title="defer 执行顺序"
  code={`package main

import "fmt"

func main() {
    defer fmt.Println("A")
    defer fmt.Println("B")
    defer fmt.Println("C")
    fmt.Println("main 主体")
}`}
  expectedOutput={`main 主体\nC\nB\nA`}
/>

<Callout type="tip" title="defer 栈是 LIFO">
多个 defer **后注册先执行**。这是因为 defer 实际压入栈中，函数返回时反向弹出。
</Callout>

## 5. 闭包

函数可以引用外部作用域的变量，形成**闭包**。

<Playground
  language="go"
  id="go-04-closure"
  title="闭包计数器"
  code={`package main

import "fmt"

func counter() func() int {
    n := 0
    return func() int {
        n++
        return n
    }
}

func main() {
    c := counter()
    fmt.Println(c())  // 1
    fmt.Println(c())  // 2
    fmt.Println(c())  // 3

    // 另一个独立的计数器
    c2 := counter()
    fmt.Println(c2()) // 1
}`}
  expectedOutput={`1\n2\n3\n1`}
/>

## 6. 函数作为值

Go 中函数是一等公民，可以赋值给变量、作为参数传递。

<Playground
  language="go"
  id="go-04-funcval"
  title="函数作为参数"
  code={`package main

import "fmt"

func apply(nums []int, f func(int) int) []int {
    out := make([]int, len(nums))
    for i, v := range nums {
        out[i] = f(v)
    }
    return out
}

func main() {
    sq := apply([]int{1, 2, 3, 4}, func(x int) int { return x * x })
    fmt.Println(sq)

    dbl := apply([]int{1, 2, 3, 4}, func(x int) int { return x * 2 })
    fmt.Println(dbl)
}`}
  expectedOutput={`[1 4 9 16]\n[2 4 6 8]`}
/>

## 7. `error` 基础

Go 用 `error` 类型表示错误，惯例是最后一个返回值为 `error`。

<Playground
  language="go"
  id="go-04-error"
  title="基本 error"
  code={`package main

import (
    "errors"
    "fmt"
)

func safeDiv(a, b int) (int, error) {
    if b == 0 {
        return 0, errors.New("除数不能为 0")
    }
    return a / b, nil
}

func main() {
    if v, err := safeDiv(10, 2); err != nil {
        fmt.Println("错误：", err)
    } else {
        fmt.Println("结果：", v)
    }
    if _, err := safeDiv(10, 0); err != nil {
        fmt.Println("错误：", err)
    }
}`}
  expectedOutput={`结果： 5\n错误： 除数不能为 0`}
/>
