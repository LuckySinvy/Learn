# 第一个 Python 程序

Python 是一门**解释型**语言：代码由解释器逐行执行，无需编译。这一章从最基础的 `print` 开始。

## 1. `print` 函数

`print` 是 Python 中最常用的输出函数，可以打印字符串、数字、变量等。

```python
print("Hello, World!")
print(42)
print(3.14)
print(True)
```

## 2. 字符串与 f-string

Python 3.6+ 支持 **f-string**，可在字符串中嵌入表达式：

<Playground
  language="python"

  code={`name = "小明"

## 3. 注释

- 单行注释以 `#` 开头
- 多行注释用三引号字符串 `"""..."""`

```python
# 这是单行注释
name = "Python"  # 行尾注释

"""
这是
多行注释
通常用于函数/类的文档说明
"""
```

## 4. 接收用户输入

`input()` 函数会暂停程序，等待用户输入一行文本并返回。

<Playground
  language="python"
  id="py-01-input"
  title="input 输入"
  code={`name = input("请输入你的名字：")
print(f"欢迎你，{name}！")`}
/>

<Callout type="tip" title="input 总是返回字符串">
`input()` 无论用户输入什么，**返回值都是字符串**。如果需要数字，需要用 `int()` 或 `float()` 转换。
</Callout>

## 5. 多个值一起打印

`print` 默认用空格分隔多个参数，结尾自动加换行：

<Playground
  language="python"
  id="py-01-multi"
  title="sep 与 end 参数"
  code={`print("a", "b", "c")              # 默认空格分隔
print("a", "b", "c", sep="-")         # 自定义分隔符
print("hello", end=" ")
print("world")                          # 自定义结尾（不换行）`}
  expectedOutput={`a b c\na-b-c\nhello world`}
/>

## 小结

- ✅ `print()` 输出内容到控制台
- ✅ `#` 写注释
- ✅ f-string 嵌入变量：`f"hello {name}"`
- ✅ `input()` 接收用户输入（总是字符串）
- ✅ `print` 的 `sep`/`end` 参数控制分隔与结尾
