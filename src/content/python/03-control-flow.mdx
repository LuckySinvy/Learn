# 流程控制

任何程序都可以分解为**顺序、选择、循环**三种结构。本章覆盖 Python 的 `if` 与 `for/while`。

## 1. `if / elif / else`

```python
if 条件1:
    ...
elif 条件2:
    ...
else:
    ...
```

```python title="成绩分级"
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "F"
print(f"分数 {score} -> 等级 {grade}")
```

</Callout>

## 2. 三元表达式

```python
status = "成年人" if age >= 18 else "未成年"
```

```python title="三元判断"
age = 16
status = "成年" if age >= 18 else "未成年"
print(f"{age}岁 -> {status}")

n = 7
parity = "偶数" if n % 2 == 0 else "奇数"
print(f"{n} 是{parity}")
```

## 3. `for` 循环

`for x in 可迭代对象:` 是最常见的循环形式。

```python title="for 循环"
# 遍历列表
fruits = ["苹果", "香蕉", "橙子"]
for f in fruits:
    print(f"我喜欢{f}")

# range 区间
for i in range(5):           # 0,1,2,3,4
    print(i, end=" ")
print()

for i in range(1, 10, 2):    # 1,3,5,7,9
    print(i, end=" ")
print()
```

## 4. `while` 循环

```python
i = 0
while i < 5:
    print(i)
    i += 1
```

```python title="while 累加"
# 1+2+...+100
s = 0
i = 1
while i <= 100:
    s += i
    i += 1
print("1 到 100 之和 =", s)
```

## 5. `break` 与 `continue`

- `break`：立即退出当前循环
- `continue`：跳过本次迭代，进入下一次

```python title="break 与 continue"
# 找第一个能被 7 整除的数
for n in range(1, 100):
    if n % 7 == 0:
        print("找到：", n)
        break

# 跳过偶数
for n in range(1, 11):
    if n % 2 == 0:
        continue
    print(n, end=" ")
print()
```

## 6. 实战：九九乘法表

```python title="九九乘法表"
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}*{i}={i*j}", end="\\t")
    print()
```
