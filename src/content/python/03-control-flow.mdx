# 流程控制

任何程序都可以分解为**顺序、选择、循环**三种结构。本章覆盖 Python 的 `if` 与 `for/while`。

## 1. `if / elif / else`

```python
if 条件1:
    ...
elif 条件2:
    ...
else:
    ...
```

## 3. `for` 循环

`for x in 可迭代对象:` 是最常见的循环形式。

<Playground
  language="python"
  id="py-03-for"
  title="for 循环"
  code={`# 遍历列表
fruits = ["苹果", "香蕉", "橙子"]
for f in fruits:
    print(f"我喜欢{f}")

for i in range(5):           # 0,1,2,3,4
    print(i, end=" ")
print()

for i in range(1, 10, 2):    # 1,3,5,7,9
    print(i, end=" ")
print()`}
  expectedOutput={`我喜欢苹果\n我喜欢香蕉\n我喜欢橙子\n0 1 2 3 4 \n1 3 5 7 9 `}
/>

## 4. `while` 循环

```python
i = 0
while i < 5:
    print(i)
    i += 1
```

<Playground
  language="python"
  id="py-03-while"
  title="while 累加"
  code={`# 1+2+...+100

while i <= 100:
    s += i
    i += 1
print("1 到 100 之和 =", s)`}
  expectedOutput={`1 到 100 之和 = 5050`}
/>

## 5. `break` 与 `continue`

- `break`：立即退出当前循环
- `continue`：跳过本次迭代，进入下一次

<Playground
  language="python"
  id="py-03-break-continue"
  title="break 与 continue"
  code={`# 找第一个能被 7 整除的数
for n in range(1, 100):
    if n % 7 == 0:
        print("找到：", n)
        break

# 跳过偶数
for n in range(1, 11):
    if n % 2 == 0:
        continue
    print(n, end=" ")
print()`}
  expectedOutput={`找到： 7\n1 3 5 7 9 `}
/>

## 小结

- ✅ `if/elif/else` 进行条件分支
- ✅ `for x in iterable` 遍历可迭代对象
- ✅ `while 条件:` 条件循环
- ✅ `break` 退出循环；`continue` 跳过本轮
- ✅ `range(start, stop, step)` 生成整数序列
- ✅ 用 4 空格缩进表示代码块
