# 变量与数据类型

Python 是**动态类型**语言：声明变量时无需指定类型，类型由值决定。

## 1. 变量赋值

```python
name = "Alice"        # 字符串 str
age = 30              # 整数 int
height = 1.75         # 浮点数 float
is_student = True     # 布尔 bool
nothing = None        # 空值 NoneType
```

## 2. 常用类型一览

| 类型 | 示例 | 说明 |
|---|---|---|
| `int` | `-1, 0, 42, 1_000_000` | 任意精度整数 |
| `float` | `3.14, -0.5, 1e10` | 双精度浮点 |
| `str` | `"hi", 'Python', '''多行'''` | 不可变字符串 |
| `bool` | `True, False` | 实际上是 `int` 的子类 |
| `NoneType` | `None` | 表示"空" |

## 4. 类型转换

Python 不会自动转换类型，需要手动调用 `int()` / `float()` / `str()` / `bool()`。

<Playground

## 5. 算术运算符

```python
print(10 + 3)   # 13
print(10 - 3)   # 7
print(10 * 3)   # 30
print(10 / 3)   # 3.3333...  真除法
print(10 // 3)  # 3          整除
print(10 % 3)   # 1          取模
print(10 ** 3)  # 1000       幂
```

## 6. 布尔值与比较

```python
print(3 > 2)    # True
print(3 == 3)   # True
print(3 != 3)   # False
print("a" < "b") # True  字符串按字典序
```

## 小结

- ✅ Python 变量无需声明类型，赋值即创建
- ✅ 常用类型：`int / float / str / bool / None`
- ✅ `type()` 查看类型
- ✅ `int()` / `float()` / `str()` 显式转换
- ✅ 算术运算符 `+ - * / // % **`，比较返回 `bool`
- ✅ Python 支持链式比较：`1 < x < 10`
