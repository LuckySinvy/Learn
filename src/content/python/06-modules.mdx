# 模块与包

当代码量变大，就需要把函数拆到不同文件里。Python 用**模块（.py 文件）**和**包（包含 __init__.py 的文件夹）**组织代码。

## 1. `import` 三种写法

```python
import math                # 引入整个模块
from math import sqrt       # 引入特定函数
from math import pi as PI   # 引入并重命名
```

```python title="import 用法"
import math
from math import sqrt
from math import pi as PI

print(math.ceil(3.2))       # 4
print(sqrt(16))              # 4.0
print(PI)                    # 3.14159...
```

## 2. `__name__ == "__main__"`

当一个 `.py` 文件被直接执行时，`__name__` 是 `"__main__"`；当被 `import` 时，是模块名。

```python
def main():
    print("running main")

if __name__ == "__main__":
    main()
```

<Callout type="tip" title="让文件既可执行又可被导入">
这个惯用法让一个文件既能 `python file.py` 直接运行，又能在被 `import` 时不自动执行。
</Callout>

## 3. 常用标准库

### 3.1 `random`

```python title="random"
import random
print(random.random())             # [0,1) 浮点
print(random.randint(1, 6))        # 1~6 整数
print(random.choice(["A", "B", "C"]))   # 随机选一个
random.seed(42)                    # 固定种子，结果可复现
print([random.randint(1, 100) for _ in range(5)])
```

### 3.2 `math`

```python title="math"
import math
print(math.pi, math.e)
print(math.factorial(6))      # 720
print(math.gcd(12, 18))       # 6
print(math.log(100, 10))      # 2.0（以10为底的对数）
```

### 3.3 `datetime`

```python title="datetime"
from datetime import datetime, timedelta
now = datetime.now()
print(now)
print(now.strftime("%Y-%m-%d %H:%M:%S"))
print((now + timedelta(days=7)).strftime("%Y-%m-%d"))
```

### 3.4 `os` 与 `sys`

```python
import os, sys
print(os.getcwd())             # 当前工作目录
print(os.listdir("."))         # 列出文件
print(sys.argv)                # 命令行参数
print(sys.version)             # Python 版本
```

## 5. 实战：随机密码生成器

```python title="随机密码生成"
import random
import string

def gen_password(length=12):
    chars = string.ascii_letters + string.digits + "!@#$%"
    return "".join(random.choice(chars) for _ in range(length))

random.seed(0)  # 让结果可复现
for _ in range(3):
    print(gen_password(10))
```
