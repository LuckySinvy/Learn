# 错误处理

程序出错时不应该直接崩溃。Python 用 `try/except` 捕获并处理异常。

## 1. 异常的代价

```python
print(1 / 0)
# ZeroDivisionError: division by zero
```

<Callout type="info" title="什么是异常">
异常（Exception）是程序运行时的错误事件。它会**中断当前执行流**，沿调用栈向上抛出，直到被 `try/except` 捕获或导致程序退出。
</Callout>

## 3. `else` 与 `finally`

- `else`：当**没有**异常时执行
- `finally`：无论是否异常都执行（常用于释放资源）

<Playground
  language="python"
  id="py-07-finally"
  title="else 与 finally"
  code={`def safe_div(a, b):
    try:
        r = a / b
    except ZeroDivisionError:
        return None
    else:
        return r          # 没出错才执行
    finally:
        print(f"  safe_div({a},{b}) 调用结束")

print(safe_div(10, 2))
print(safe_div(10, 0))`}
  expectedOutput={`  safe_div(10,2) 调用结束\n5\n  safe_div(10,0) 调用结束\nNone`}/>
/>

## 4. 常见异常类型

| 异常 | 触发场景 |
|---|---|
| `ValueError` | 类型对但值不合法，如 `int("abc")` |
| `TypeError` | 类型错误，如 `"1" + 1` |
| `ZeroDivisionError` | 除以 0 |
| `IndexError` | 序列下标越界 |
| `KeyError` | 字典键不存在 |
| `FileNotFoundError` | 打开不存在的文件 |
| `AttributeError` | 对象无此属性 |

## 6. 自定义异常

<Playground
  language="python"
  id="py-07-custom"
  title="自定义异常"
  code={`class InsufficientFundsError(Exception):
    """余额不足异常"""
    def __init__(self, balance, amount):
        super().__init__(f"余额 {balance}，尝试取出 {amount}")
        self.balance = balance
        self.amount = amount

def withdraw(balance, amount):
    if amount > balance:
        raise InsufficientFundsError(balance, amount)
    return balance - amount

try:
    withdraw(100, 200)
except InsufficientFundsError as e:
    print("操作失败：", e)`}
  expectedOutput={`操作失败： 余额 100，尝试取出 200`}

## 小结

- ✅ `try/except` 捕获异常；`else` 无异常时执行；`finally` 总是执行
- ✅ 多个 except 按顺序匹配
- ✅ `raise` 主动抛异常
- ✅ 自定义异常继承 `Exception`
- ✅ 不要用 `except:` 吞掉所有异常（会包括 `KeyboardInterrupt` 等）
- ✅ 异常信息（`e`）是宝贵的调试线索
