# 枚举与模式匹配

**枚举（enum）** 让你定义一个「可能是几种类型之一」的类型。Rust 的枚举极强大：每个变体可携带不同数据。

## 1. 基础枚举

```rust
enum Direction {
    North,
    South,
    East,
    West,
}

fn main() {
    let d = Direction::North;
}
```

## 2. 携带数据的枚举

<Playground
  language="rust"
  id="rust-09-enum-data"
  title="携带数据的枚举"
  code={`enum Message {
    Quit,                        // 无数据
    Move { x: i32, y: i32 },     // 具名字段
    Write(String),               // 元组式
    ChangeColor(i32, i32, i32),
}

fn handle(m: &Message) {
    match m {
        Message::Quit => println!("退出"),
        Message::Move { x, y } => println!("移动到 ({}, {})", x, y),
        Message::Write(text) => println!("写入: {}", text),
        Message::ChangeColor(r, g, b) => println!("变色 {} {} {}", r, g, b),
    }
}

fn main() {
    handle(&Message::Write(String::from("hi")));
    handle(&Message::Move { x: 3, y: 4 });
    handle(&Message::ChangeColor(255, 0, 0));
    handle(&Message::Quit);
}`}
  expectedOutput={`写入: hi\n移动到 (3, 4)\n变色 255 0 0\n退出`}
/>

## 3. Option：没有 null 的世界

Rust 没有 `null`。用标准库 `Option<T>` 表达「可能有值」：

```rust
enum Option<T> {
    Some(T),
    None,
}
```

用它彻底消灭空指针异常：

<Playground
  language="rust"
  id="rust-09-option"
  title="Option 与 match"
  code={`fn divide(a: f64, b: f64) -> Option<f64> {
    if b == 0.0 { None } else { Some(a / b) }
}

fn main() {
    match divide(10.0, 2.0) {
        Some(v) => println!("结果 {}", v),
        None => println!("除零错误"),
    }

    match divide(1.0, 0.0) {
        Some(v) => println!("结果 {}", v),
        None => println!("除零错误"),
    }
}`}
  expectedOutput={`结果 5\n除零错误`}
/>

<Callout type="warn" title="Option 强制你处理 None">
因为 `Option<T>` 不是 `T`，你**必须**用 `match`/`if let` 把它拆开才能拿到里面的值。编译器逼你处理「没有值」的情况，从根上避免空引用崩溃。
</Callout>

## 4. if let / while let 简化匹配

只关心一个分支时，不必写完整 `match`：

<Playground
  language="rust"
  id="rust-09-if-let"
  title="if let / while let"
  code={`fn main() {
    let some = Some(7);
    if let Some(n) = some {
        println!("得到 {}", n);
    }

    let mut stack = vec![Some(1), None, Some(2)];
    while let Some(v) = stack.pop() {
        println!("{:?}", v);
    }
}`}
  expectedOutput={`得到 7\nSome(2)\nNone\nSome(1)`}
/>

<Callout type="tip" title="match 还是 if let">
需要穷尽处理所有变体用 `match`；只关心某个变体、其余忽略时用 `if let`，更简洁。
</Callout>

## 5. 枚举也能有方法

```rust
impl Message {
    fn call(&self) {
        // 可在 impl 里为枚举定义方法
    }
}
```

## 6. 实战：计算表达式

```rust
enum Expr {
    Num(i32),
    Add(Box<Expr>, Box<Expr>),
}
```

<Callout type="exercise" title="练习">
定义一个 `enum Shape { Circle(f64), Rectangle(f64, f64) }`，写一个 `fn area(s: &Shape) -> f64` 用 `match` 计算面积（圆用 π·r²）。再补一个 `Triangle` 变体，体会穷尽性要求你同步更新 match。
</Callout>

## 小结

- 枚举变体可携带任意数据（单元/元组/结构体风格）
- `Option<T>` 替代 null，强制处理 `None`
- `match` 穷尽匹配；`if let` 简化单分支
- 枚举同样可用 `impl` 加方法
