# 切片

**切片（slice）** 是「对一段连续序列的视图」，本身不拥有数据，只是借用。它让你安全地引用集合的一部分。

## 1. 字符串切片 &str

<Playground
  language="rust"
  id="rust-07-str-slice"
  title="字符串切片"
  code={`fn main() {
    let s = String::from("hello world");
    let hello = &s[0..5];     // "hello"
    let world = &s[6..11];    // "world"
    println!("{} + {}", hello, world);
}`}
  expectedOutput={`hello + world`}
/>

`&str` 是「字符串切片」：一个指针 + 长度。字符串字面量 `"abc"` 的类型就是 `&'static str`——指向二进制里的只读数据。

<Callout type="info" title="为什么函数参数用 &str 而非 &String">
`&str` 既能接 `String` 的切片（`&s[..]`），也能接字面量。写 `fn f(s: &str)` 最通用；`&String` 只接受 String。
</Callout>

## 2. 切片是借用

对 `s` 取切片时，同时持有一个不可变借用。因此切片存活期间，不能对 `s` 做可变操作：

<Playground
  language="rust"
  id="rust-07-first-word"
  title="取第一个单词"
  code={`fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &b) in bytes.iter().enumerate() {
        if b == b' ' {
            return &s[0..i];
        }
    }
    &s[..]
}

fn main() {
    println!("{}", first_word("hello world"));
    println!("{}", first_word("single"));
}`}
  expectedOutput={`hello\nsingle`}
/>

<Callout type="warn" title="切片的边界检查">
`&s[0..100]` 若越界会 panic。切片必须在 UTF-8 字符边界上切，否则编译/运行报错——Rust 不会让你把一个多字节字符劈成两半。
</Callout>

## 3. 数组切片

<Playground
  language="rust"
  id="rust-07-array-slice"
  title="数组切片"
  code={`fn main() {
    let arr = [1, 2, 3, 4, 5];
    let mid = &arr[1..4];     // [2, 3, 4]，类型 &[i32]
    let sum: i32 = mid.iter().sum();
    println!("{:?}", mid);
    println!("{}", sum);
}`}
  expectedOutput={`[2, 3, 4]\n9`}
/>

数组切片 `&[T]` 与 `Vec<T>` 的切片同理，都是「指针 + 长度」的胖指针。

## 4. 切片作为通用参数

很多 API 接受切片而非具体集合，便于复用：

```rust
fn largest(nums: &[i32]) -> i32 {
    *nums.iter().max().unwrap()
}
```

<Callout type="tip" title="切片让函数更通用">
接收 `&[i32]` 的函数，既能吃数组 `&arr[..]`，也能吃 `Vec` 的 `&vec[..]`。优先用切片做只读接口。
</Callout>

## 5. 对比字符串与切片

| 类型 | 拥有数据 | 可修改 | 典型用途 |
|---|---|---|---|
| `String` | 是 | 是 | 需要构造/修改字符串 |
| `&str` | 否（借用） | 否 | 只读查看、函数参数 |

<Callout type="exercise" title="练习">
写一个 `fn second_word(s: &str) -> &str` 返回第二个单词（按空格切分）。对 `"the quick brown"` 调用，验证返回 `"quick"`。注意处理不足两个词时的边界。

<Answer>
**参考答案：**

**写法一：手动遍历字节（贴近本章的 `first_word` 思路）**

```rust
fn second_word(s: &str) -> &str {
    let bytes = s.as_bytes();
    let mut start = None;   // 第二个单词的起始下标

    for (i, &b) in bytes.iter().enumerate() {
        if b == b' ' {
            if start.is_none() {
                start = Some(i + 1);   // 第一个空格之后 = 第二个单词开头
            } else {
                // 第二个空格：第二个单词到此结束
                return &s[start.unwrap()..i];
            }
        }
    }

    match start {
        Some(i) => &s[i..],   // 只有两个单词，取到结尾
        None => "",           // 不足两个单词，返回空串
    }
}

fn main() {
    println!("[{}]", second_word("the quick brown"));  // [quick]
    println!("[{}]", second_word("the quick"));        // [quick]
    println!("[{}]", second_word("single"));           // []
    println!("[{}]", second_word(""));                 // []
}
```

**写法二：用迭代器（更简洁、更地道，强烈推荐）**

```rust
fn second_word(s: &str) -> &str {
    s.split_whitespace().nth(1).unwrap_or("")
}
```

一行搞定，而且比写法一更健壮：`split_whitespace()` 会自动忽略连续空格、制表符和换行，`nth(1)` 取第二项，`unwrap_or("")` 处理不存在的情况。

**写法三：返回 `Option`（接口更诚实）**

```rust
fn second_word(s: &str) -> Option<&str> {
    s.split_whitespace().nth(1)
}

fn main() {
    match second_word("the quick brown") {
        Some(w) => println!("第二个单词：{}", w),
        None => println!("不足两个单词"),
    }
}
```

用 `Option` 明确区分了「第二个单词是空串」和「根本没有第二个单词」，调用方无法忽略边界情况。在真实项目里这通常是最好的选择。

**边界情况一览：**

| 输入 | 写法一/二返回 | 写法三返回 |
|---|---|---|
| `"the quick brown"` | `"quick"` | `Some("quick")` |
| `"the quick"` | `"quick"` | `Some("quick")` |
| `"single"` | `""` | `None` |
| `""` | `""` | `None` |
| `"a  b"`（连续空格） | 写法一返回 `""`，写法二返回 `"b"` | `Some("b")` |

**为什么返回值不用标注生命周期？**

因为触发了**生命周期省略规则**：函数只有一个引用参数时，返回的引用被自动认为借用自它，等价于：

```rust
fn second_word<'a>(s: &'a str) -> &'a str
```

这也说明了返回值和输入的关系——切片只是**借用**了原字符串的一段，没有复制任何数据。所以原字符串必须活得比返回的切片久：

```rust
let word;
{
    let s = String::from("the quick brown");
    word = second_word(&s);   // ❌ s 马上就要 drop 了
}
println!("{}", word);         // 编译器会拒绝：borrowed value does not live long enough
```
</Answer>
</Callout>

## 小结

- 切片是对连续序列的「视图」，胖指针（指针+长度）
- `&str` 用于只读字符串，`&[T]` 用于数组/Vec 片段
- 取切片即借用，与可变操作互斥
- 函数参数优先用切片，通用且零拷贝
