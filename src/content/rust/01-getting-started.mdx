# Rust 入门与环境搭建

Rust 是一门注重**内存安全**与**零成本抽象**的系统级编程语言。它能在不依赖垃圾回收的前提下，在编译期就消灭大多数内存错误。本章带你从零把环境跑起来。

## 1. 安装 Rust 工具链

官方推荐用 `rustup` 安装，它会同时带来编译器 `rustc` 和包管理器 `cargo`：

```bash
# 安装 rustup（会附带 stable 工具链与 cargo）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 验证安装
rustc --version
cargo --version
```

<Callout type="tip" title="国内网络加速">
若下载慢，可先设置镜像：`export RUSTUP_DIST_SERVER=https://rsproxy.cn`，再执行安装脚本。更新时用 `rustup update`。
</Callout>

## 2. 第一个 Hello World

不用 cargo 也能直接编译单个文件，适合快速验证：

<Playground

    println!("Hello, world!");
}`}
  expectedOutput={`Hello, world!`}

```bash
rustc main.rs      # 编译生成可执行文件 main
./main             # 运行，输出 Hello, world!
```

`println!` 末尾的 `!` 表示它是一个**宏**而非普通函数；字符串里的 `{}` 是占位符（在代码块里写没问题）。

## 3. 用 cargo 管理项目

真实项目都用 cargo。它负责构建、运行、测试与依赖管理：

```bash
cargo new hello --bin     # 创建二进制项目
cd hello
cargo run                 # 编译并运行
cargo build --release     # 发布优化构建，产物在 target/release
```

<Callout type="info" title="cargo 项目的标准结构">
`Cargo.toml` 是清单（名称、版本、依赖）；`src/main.rs` 是入口；`target/` 存放编译产物，`Cargo.lock` 锁定依赖版本。库项目用 `cargo new hello --lib`，入口改为 `src/lib.rs`。
</Callout>

## 4. Cargo.toml 简介

```toml
[package]
name = "hello"
version = "0.1.0"
edition = "2021"

[dependencies]
# 在这里添加第三方 crate，例如 serde = "1.0"
```

## 5. 编辑-编译-运行的循环

Rust 是** ahead-of-time 编译**语言：先 `cargo build` 生成机器码，再运行。编译期检查极其严格——很多 bug 在编译阶段就被拦下，换来的是「编译通过基本就能跑对」的踏实感。

<Callout type="exercise" title="练习">
用 `cargo new hello --bin` 创建项目，把输出改成你的名字（例如 `Hello, 小明!`），再 `cargo run` 确认成功。然后试试故意写错一个字母让编译失败，观察编译器的友好报错。

<Answer>
**参考答案：**

**第 1 步：创建并运行项目**

```bash
cargo new hello --bin
cd hello
cargo run
# 输出：
#    Compiling hello v0.1.0 (/path/to/hello)
#     Finished dev [unoptimized + debuginfo] target(s) in 0.35s
#      Running `target/debug/hello`
# Hello, world!
```

**第 2 步：修改 `src/main.rs`**

```rust
fn main() {
    println!("Hello, 小明!");
}
```

再次 `cargo run`，输出变为 `Hello, 小明!`。

**第 3 步：故意制造编译错误**

把 `println!` 写成 `printl!`：

```rust
fn main() {
    printl!("Hello, 小明!");
}
```

编译器会给出类似这样的报错：

```text
error: cannot find macro `printl` in this scope
 --> src/main.rs:2:5
  |
2 |     printl!("Hello, 小明!");
  |     ^^^^^^ help: a macro with a similar name exists: `println`
```

**观察要点：**

- 报错里有**错误码/描述**、**出错文件与行列号**、用 `^^^` 标出的**精确位置**
- 最有价值的是 `help:` 那一行——Rust 编译器会主动猜测你的意图并给出修复建议
- 另一个常见错误是漏掉分号，报错会提示 `` help: add `;` here ``
- 这种「编译器即导师」的体验是 Rust 的一大特色：遇到红色报错先完整读一遍，通常答案就写在里面

**小提示：** `cargo run` 会自动先 build 再执行；只想检查语法而不生成可执行文件时，用 `cargo check` 更快。
</Answer>
</Callout>

## 小结

- 用 `rustup` 安装工具链，得到 `rustc` 与 `cargo`
- `println!` 是宏，编译期处理
- 真实项目用 `cargo new` 创建，`cargo run` 一键构建运行
- `Cargo.toml` 管理元数据与依赖，`edition = "2021"` 指定语言版本
