# 函数与控制流

Rust 中**控制流也是表达式**——它们能返回值，这让代码更简洁。

## 1. 函数 fn

<Playground
  language="rust"
  id="rust-04-fn"
  title="函数 fn"
  code={`fn add(a: i32, b: i32) -> i32 {
    a + b          // 无分号 = 返回值（表达式）
}

fn main() {
    let r = add(2, 3);
    println!("{}", r);
}`}
  expectedOutput={`5`}
/>

<Callout type="tip" title="表达式 vs 语句">
以分号结尾是「语句」（无返回值）；不加结尾分号的最后一个表达式就是返回值。也可以显式 `return x;`，但通常省略更地道。
</Callout>

## 2. if / else 是表达式

```rust
fn main() {
    let n = 7;
    let desc = if n % 2 == 0 { "偶数" } else { "奇数" };
    println!("{} 是 {}", n, desc);
}
```

<Callout type="warn" title="两个分支类型要一致">
`if/else` 作为表达式返回值时，所有分支必须返回**同一类型**，否则编译失败。
</Callout>

## 3. 循环：loop / while / for

<Playground
  language="rust"
  id="rust-04-loops"
  title="循环"
  code={`fn main() {
    // loop：无限循环，用 break 退出并可带值
    let mut i = 0;
    let result = loop {
        i += 1;
        if i == 5 { break i * 10; }
    };
    println!("loop 结果 = {}", result);

    // while：条件循环
    let mut n = 3;
    while n > 0 {
        n -= 1;
    }

    // for：遍历集合，最常用
    for x in 0..3 {
        println!("x = {}", x);
    }
}`}
  expectedOutput={`loop 结果 = 50\nx = 0\nx = 1\nx = 2`}
/>

## 4. match 穷尽匹配

`match` 类似增强版 `switch`，但**必须覆盖所有可能**：

<Playground
  language="rust"
  id="rust-04-match"
  title="match 穷尽匹配"
  code={`fn describe(n: i32) -> &'static str {
    match n {
        0 => "零",
        1 | 2 => "小",
        3..=9 => "个位数",
        _ => "其他",     // 通配，保证穷尽
    }
}

fn main() {
    println!("{}", describe(0));
    println!("{}", describe(2));
    println!("{}", describe(5));
    println!("{}", describe(100));
}`}
  expectedOutput={`零\n小\n个位数\n其他`}
/>

<Callout type="info" title="为什么 match 安全">
编译器强制「穷尽性」：漏掉任何分支（包括通配 `_`）都会编译报错。这避免了「忘了处理某种情况」的 bug。
</Callout>

## 5. 循环标签与 continue

嵌套循环可用 `'label` 跳出指定层：

```rust
fn main() {
    'outer: for i in 0..3 {
        for j in 0..3 {
            if i + j == 2 { break 'outer; }
        }
    }
}
```

<Callout type="exercise" title="练习">
写一个函数 `fn fib(n: u32) -> u32` 用 `loop` 计算第 n 个斐波那契数（用三个变量滚动即可），再用 `for` 打印前 10 项。体会 break 带返回值与 for 遍历。

<Answer>
**参考答案：**

```rust
fn fib(n: u32) -> u32 {
    if n == 0 {
        return 0;
    }

    let mut prev = 0u32;   // f(0)
    let mut curr = 1u32;   // f(1)
    let mut i = 1u32;

    loop {
        if i == n {
            break curr;    // break 带值：整个 loop 表达式的值就是 curr
        }
        let next = prev + curr;
        prev = curr;
        curr = next;
        i += 1;
    }
}

fn main() {
    for n in 0..10 {
        println!("fib({}) = {}", n, fib(n));
    }
}
```

**输出：**

```text
fib(0) = 0
fib(1) = 1
fib(2) = 1
fib(3) = 2
fib(4) = 3
fib(5) = 5
fib(6) = 8
fib(7) = 13
fib(8) = 21
fib(9) = 34
```

**要点解析：**

- **`break` 带值**：`break curr;` 让 `loop` 整体成为一个求值为 `curr` 的表达式。因为它是函数体最后一个表达式（无分号），它的值直接成为函数返回值。这是 `loop` 独有的能力——`while` 和 `for` 的 `break` 不能带值
- **三变量滚动**：`prev`、`curr` 保存相邻两项，`next` 是临时值。每轮向前滚动一格，空间复杂度 O(1)，比递归实现高效得多
- **边界处理**：`n == 0` 单独提前 `return 0`，否则循环从 `i = 1` 开始会直接返回 `curr = 1`，结果就错了
- **`0..10`** 是左闭右开区间，产生 0 到 9 共 10 个数；要含 10 得写 `0..=10`

**用 `while` 改写（更常见的风格）：**

```rust
fn fib(n: u32) -> u32 {
    let (mut prev, mut curr) = (0u32, 1u32);
    let mut i = 0;
    while i < n {
        let next = prev + curr;
        prev = curr;
        curr = next;
        i += 1;
    }
    prev   // 循环 n 次后，prev 就是 f(n)
}
```

这个版本连 `n == 0` 的特判都省了：循环 0 次时 `prev` 恰好是 0。

**溢出提醒：** `u32` 大约在 `fib(48)` 处溢出。Debug 模式会 panic，生产代码建议改用 `u64`，或用 `checked_add` 返回 `Option` 来安全处理。
</Answer>
</Callout>

## 小结

- 函数返回值用「无分号表达式」，或显式 `return`
- `if/else` 是表达式，分支类型须一致
- `loop` 可 `break` 带值；`for` 遍历最常用
- `match` 强制穷尽匹配，通配 `_` 兜底
