# 字符串深入

Rust 的字符串是 UTF-8 编码，且分 `String`（拥有）与 `&str`（借用）两种形态。理解它们能避开大量新手坑。

## 1. String vs &str

```rust
let owned: String = String::from("你好");   // 堆上，可变、拥有
let borrowed: &str = "你好";                 // 只读、借用（字面量在二进制里）
```

- `String`：可在堆上增长、修改，拥有数据。
- `&str`：对 UTF-8 字节序列的视图，不可变、不拥有。

<Callout type="info" title="函数参数为何用 &str">
`&str` 既能接收 `String` 切片也能接收字面量，最通用。需要修改/构建字符串时才用 `String`。
</Callout>

## 2. UTF-8 编码陷阱

一个字符可能占多个字节。按**字节**索引会出错：

<Playground
  language="rust"
  id="rust-25-utf8"
  title="UTF-8 字节与字符"
  code={`fn main() {
    let s = String::from("你好");
    // println!("{}", &s[0..1]);   // 运行错误：切在字符中间
    println!("字节数 = {}", s.len());              // 6，UTF-8 字节
    println!("字符数 = {}", s.chars().count());   // 2，按 Unicode 字符
}`}
  expectedOutput={`字节数 = 6
字符数 = 2`}
/>

<Callout type="warn" title="不要按字节切字符串">
中文字符在 UTF-8 中占 3 字节。对 `String` 用 `[0..1]` 切片极易落在字符中间，Rust 会直接 panic 来阻止产生非法 UTF-8。
</Callout>

## 4. 拼接与转换

```rust
let mut s = String::from("Hello");
s.push_str(", Rust");
s.push('!');
let combined = format!("{} {}", s, 2024);

let n = 42;
let ns = n.to_string();          // 数字 -> String
let parsed: i32 = "42".parse().unwrap();   // &str -> 数字
```

## 5. &str 与 String 互转

```rust
let s: String = "hi".to_string();   // &str -> String
let r: &str = &s;                    // String -> &str（取切片）
let r2: &str = s.as_str();           // 等价写法
```

<Callout type="tip" title="尽量晚地转成 String">
很多函数接受 `&str` 即可，不必先 `to_string()`。只有需要所有权或修改时才升级为 `String`，能减少不必要的分配。
</Callout>

## 6. 常见坑速查

| 坑 | 正确做法 |
|---|---|
| `&s[0..1]` 切中文 | 用 `chars()` / `char_indices()` |
| 用 `+` 拼接 `&str` | 右侧须是 `&str`（`s + &tail`） |
| 忘记 UTF-8 长度 | `s.len()` 是字节数，`chars().count()` 是字符数 |

<Callout type="exercise" title="练习">
写一个 `fn reverse_chars(s: &str) -> String`，按 Unicode 字符反转字符串（用 `chars().rev().collect()`）。对「Rust语言」调用，验证是「言语tsuR」而非按字节乱码。

<Answer>
**参考答案：**

```rust
fn reverse_chars(s: &str) -> String {
    s.chars().rev().collect()
}

fn main() {
    let s = "Rust语言";

    println!("原串：{}", s);
    println!("反转：{}", reverse_chars(s));

    println!("字节数 = {}", s.len());              // 10
    println!("字符数 = {}", s.chars().count());    // 6

    // 更多例子
    println!("{}", reverse_chars("hello"));        // olleh
    println!("{}", reverse_chars("你好世界"));      // 界世好你
    println!("{}", reverse_chars(""));             // 空串
}
```

**输出：**

```text
原串：Rust语言
反转：言语tsuR
字节数 = 10
字符数 = 6
hello -> olleh
你好世界 -> 界世好你
```

**为什么 `Rust语言` 是 10 字节？**

`R`、`u`、`s`、`t` 是 ASCII，各占 1 字节；`语`、`言` 是中文，UTF-8 下各占 3 字节。合计 `4 + 3 + 3 = 10`。

**如果按字节反转会怎样？**

```rust
fn reverse_bytes_wrong(s: &str) -> String {
    let bytes: Vec<u8> = s.bytes().rev().collect();
    String::from_utf8_lossy(&bytes).to_string()
}

fn main() {
    println!("{}", reverse_bytes_wrong("Rust语言"));
    // 输出：������tsuR  —— 中文字符的字节序被打乱，变成非法 UTF-8
}
```

中文字符的 3 个字节顺序被颠倒后，不再构成合法的 UTF-8 序列。`from_utf8_lossy` 只能用替换字符 `U+FFFD` 顶替。这正是「Rust 不允许你直接按字节索引字符串」的原因——它宁可让你多写 `.chars()`，也不让你悄悄产出乱码。

**`chars()` 也不是万能的：字素簇（grapheme cluster）**

`chars()` 迭代的是 **Unicode 标量值**，但「用户眼中的一个字符」可能由多个标量值组成：

```rust
fn main() {
    // 带组合音标的字符
    let s = "e\u{301}";   // e + 组合尖音符 = é
    println!("看起来是：{}", s);                  // é
    println!("字符数 = {}", s.chars().count());   // 2！
    println!("反转后：{}", reverse_chars(s));     // ́e —— 音标跑到前面去了

    // emoji 家族（由多个 emoji 加零宽连接符组成）
    let family = "👨‍👩‍👧";
    println!("字符数 = {}", family.chars().count());   // 5
}
```

要正确处理这类情况，需要 `unicode-segmentation` crate：

```toml
[dependencies]
unicode-segmentation = "1"
```

```rust
use unicode_segmentation::UnicodeSegmentation;

fn reverse_graphemes(s: &str) -> String {
    s.graphemes(true).rev().collect()
}

fn main() {
    let s = "e\u{301}llo";
    println!("{}", reverse_chars(s));       // 音标错位
    println!("{}", reverse_graphemes(s));   // olle� —— 正确保持 é 完整
}
```

**三个层次，按需选择：**

| 层次 | 方法 | 适用场景 |
|---|---|---|
| 字节 `u8` | `.bytes()` / `.len()` | 网络传输、文件大小、二进制处理 |
| 标量值 `char` | `.chars()` | 大多数文本处理，本题的正确答案 |
| 字素簇 | `.graphemes(true)` | 光标移动、截断显示、用户可见的"字符数" |

**其他常见的字符串操作：**

```rust
fn main() {
    let s = "Hello, 世界!";

    // 带字节索引的字符遍历
    for (i, c) in s.char_indices() {
        print!("{}:{} ", i, c);
    }
    // 0:H 1:e 2:l 3:l 4:o 5:, 6:  7:世 10:界 13:!
    // 注意索引不连续——中文占 3 字节
    println!();

    // 安全地取前 n 个字符（不会 panic）
    let prefix: String = s.chars().take(5).collect();
    println!("{}", prefix);   // Hello

    // 查找与替换
    println!("{:?}", s.find('世'));           // Some(7) —— 字节索引
    println!("{}", s.replace("世界", "Rust"));

    // 大小写、去空白、切分
    println!("{}", "  hi  ".trim());
    println!("{:?}", "a,b,c".split(',').collect::<Vec<_>>());
    println!("{}", "abc".to_uppercase());

    // 判断
    println!("{}", s.starts_with("Hello"));
    println!("{}", s.contains("世"));
}
```

**安全截断字符串的实用函数**

直接 `&s[0..n]` 可能切在字符中间导致 panic。这个版本永远安全：

```rust
fn truncate_chars(s: &str, max_chars: usize) -> String {
    s.chars().take(max_chars).collect()
}

fn main() {
    println!("{}", truncate_chars("Rust语言编程", 6));   // Rust语言
}
```

也可以用 `char_indices` 找到安全的字节边界，这样能返回 `&str` 而不用分配新 `String`：

```rust
fn truncate_str(s: &str, max_chars: usize) -> &str {
    match s.char_indices().nth(max_chars) {
        Some((idx, _)) => &s[..idx],
        None => s,   // 字符数不足，返回全部
    }
}
```

## 小结

- `String` 拥有/可改；`&str` 借用/只读，最通用
- UTF-8 下不要按字节切片，用 `chars()`
- 拼接用 `push_str`/`+`/`format!`；解析用 `parse()`
- 晚转 `String`、早用 `&str` 减少分配
