# 创建第一个应用（对话型）

理论够了，动手建你的第一个 **对话型应用（Chatbot）**。本章走通「创建 → 编排 → 调试 → 预览」的最小闭环。

## 1. 创建应用

1. 控制台首页点「**创建应用**」
2. 选择「**对话型应用**」
3. 填写名称（如「产品小助手」）、图标、描述
4. 点击创建，进入**编排（Orchestrate）**页面

编排页是应用的核心工作室，左侧是配置区，右侧是实时**调试与预览（Preview）** 窗口。

<Callout type="tip" title="先用默认跑通">
第一次不要急着加知识库和工具。先用默认模板的空对话跑通，确认「能聊」，再逐步加料，避免出问题分不清在哪一层。
</Callout>

## 2. 编排入口速览

编排页主要区域：

- **提示词（Prompt）**：系统提示词编辑区，定义角色与行为
- **上下文（Context）**：关联知识库（第 4、5 章内容）
- **变量（Variables）**：从外部传入的参数（第 8 章）
- **工具（Tools）**：给模型挂载能力（第 9 章）
- **模型（Model）**：选择底层大模型、温度等参数
- **开场白 / 建议问题**：提升首次体验

## 3. 写一段系统提示词

在提示词区填入：

```text
你是一个友好的「产品小助手」，服务于 Acme 公司的用户。
请用简洁、准确的中文回答用户关于产品功能与使用方法的问题。
如果你不确定答案，请如实说明，不要编造。
```

设置模型（如 `gpt-4o-mini` 或本地 Ollama 模型），温度设 `0.7`。

## 4. 调试与预览

右侧预览窗口直接输入问题测试：

```text
你：你们的产品支持导出 PDF 吗？
助手：根据现有信息，我暂时无法确认导出 PDF 的具体支持情况……
```

此时还没接知识库，模型只能基于通用知识回答——这正是下一步要补的。

<Callout type="warn" title="预览不等于发布">
预览里的对话只存在于当前会话，不会污染生产日志。大胆试，试完不满意直接改提示词重来。
</Callout>

## 5. 关联知识库（可选，接第 4 章）

在「上下文」区添加第 4 章建的知识库，再问同样的问题：

```text
你：你们的产品支持导出 PDF 吗？
助手：支持。您可以在「设置 → 导出」中选择 PDF 格式……
（答案明显更贴合你的资料）
```

## 6. 保存与版本

- 每次修改点「**保存**」固化配置
- 可点「**发布**」生成线上版本，发布后可「**回到草稿**」继续迭代
- 支持查看**历史版本**并回滚

创建一个对话型应用，写一段系统提示词，并在预览里分别测试「无知识库」和「加知识库」两种情况，体会上下文带来的变化。

<Answer>
**参考答案：**

**第一步：创建应用**

首页「创建应用 → 对话型应用」，名称填「产品小助手」，模型选一个便宜快速的（如 `gpt-4o-mini` / `qwen-plus` / 本地 `qwen2.5:7b`），温度先设 `0.7`。

**第二步：一段可直接用的系统提示词**

```text
# 角色
你是 Acme 公司的「产品小助手」，服务对象是正在使用我们产品的客户。

# 任务
用简洁、准确的中文回答用户关于产品功能、使用方法和常见问题的提问。

# 回答要求
1. 优先依据【上下文】中提供的资料作答，并在关键结论后标注来源要点。
2. 若上下文中没有相关信息，直接回答「抱歉，我在现有资料中没有找到相关信息，
   建议联系人工客服」，不要根据常识推测或编造。
3. 步骤类问题请用有序列表输出，每步一句话，不要长篇大论。
4. 不承诺资料中未写明的时效、价格与优惠。
5. 保持礼貌、专业，不使用夸张营销用语。
```

**为什么这么写**：角色定位 + 任务 + 明确的边界约束。其中第 2 条「找不到就说找不到」是**对比实验能否观察出差异的前提**——如果不写，无知识库时模型会自信地编一套说辞，你反而看不出上下文起了什么作用。

**第三步：设计对比问题（这是练习的核心）**

要挑那种「**只有看过你的文档才可能答对**」的问题，而不是通用常识题：

| 好的对比问题 | 为什么好 |
|---|---|
| 「导出 PDF 的入口在哪个菜单？」 | 答案是产品特定路径，通用知识答不出 |
| 「企业版最多支持多少个成员？」 | 具体数字，编造会明显穿帮 |
| 「ORD 开头的订单号在哪里查？」 | 专有格式，考验关键词召回 |
| ~~「什么是 SaaS？」~~ | 通用常识，两种情况回答一样，测不出差异 |

**第四步：记录两轮结果**

```text
【无知识库】
问：导出 PDF 的入口在哪个菜单？
答：抱歉，我在现有资料中没有找到相关信息，建议联系人工客服。
   （若提示词里没写第 2 条约束，这里大概率会看到模型胡诌一个
     「设置 → 通用 → 导出」之类不存在的路径）

【加知识库】
问：导出 PDF 的入口在哪个菜单？
答：您可以在「设置 → 导出」中选择 PDF 格式，支持导出当前视图或全部数据。
   引用来源：产品手册 v2.1 · 片段 #7（相似度 0.82）
```

**你应该观察到的四点变化**

1. **答案变具体**：从「无法确认」变成带菜单路径、数字、步骤的确切回答。
2. **出现引用标注**：回答下方多了「引用与归属」区域，可展开查看命中的片段、来源文档和相似度分数——这是排查问题的第一手证据。
3. **响应变慢一点**：多了「向量化提问 → 检索 → 拼接上下文」的环节，首字延迟通常增加几百毫秒。
4. **Token 消耗上升**：召回的片段会被塞进提示词，输入 Token 明显增加（TopK 越大增得越多）。这也是 TopK 不宜盲目调大的现实原因。

**排查小技巧**

如果加了知识库但答案没变化，按这个顺序查：

```text
1. 知识库状态是否为「可用」？还在索引中就查不到
2. 应用是否真的关联了知识库？「上下文」区要能看到它
3. 展开「引用与归属」，看是否有召回
   ├─ 无召回 → 检索问题：降低相似度阈值 / 改混合检索（回第 5 章）
   └─ 有召回但答案没用上 → 提示词问题：明确要求「依据上下文作答」
4. 改完提示词记得点「保存」，预览用的是当前草稿配置
```

**加分项：加上开场白与建议问题**

在编排页底部配置，能显著提升首次使用体验：

```text
开场白：
你好！我是 Acme 产品小助手，可以帮你解答产品功能与使用方面的问题。

建议问题：
- 如何导出数据？
- 忘记密码怎么办？
- 企业版和专业版有什么区别？
```

## 小结

- 创建对话型应用 → 进入编排页（配置 + 实时预览）
- 先空跑通，再逐步加提示词、知识库、工具
- 预览用于调试，发布才生成线上版本且支持回滚
